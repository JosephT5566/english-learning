## 2026-08-21 — Project direction

### Outcome

- Chose to evolve the existing English Learning repository into the primary full-stack training project.
- Selected Python, FastAPI, and PostgreSQL for the backend direction.
- Added Japanese as a second learning section using a shared language-aware model.
- Added AI-assisted card authoring as a later milestone after the database migration and deployment.
- Deferred semantic search until the transactional core is dependable.

### Decisions and reasoning

- An existing product migration provides stronger evidence of compatibility, data reconciliation, and end-to-end ownership than an unrelated tutorial application.
- English and Japanese should share cards, review behavior, authorization, and APIs while allowing optional language-specific fields.
- AI output should remain an editable draft until the authenticated user confirms it.
- The training records should separate roadmap, current memory, chronological learning, decisions, and verified evidence.

### Corrections and uncertainties

- The earlier marketplace-focused plan was replaced by a product-specific English Learning migration plan.
- Semantic search was initially considered a near-term feature and is now deferred.
- The exact multilingual schema, scheduling algorithm, deployment provider, and AI provider remain open decisions.
